# Monika — спутница на рабочем столе

Маленькая программа для Windows: Моника из *Doki Doki Literature Club* живёт в углу экрана, болтает с тобой через нейросеть, помнит, о чём вы говорили, ставит напоминания, смотрит на твой экран, играет в мини-игры и иногда ломает четвёртую стену.

Персонаж и арт принадлежат их авторам. \\\*\\\*Спрайты в репозиторий не входят\\\*\\\*, их нужно добавить самому (см. \\\[Спрайты](#спрайты)). ## Что умеет

* **Чат с характером.** Моника отвечает в своём стиле и меняет эмоцию (6 спрайтов).
* **Память.** Помнит факты о тебе и историю разговора между запусками.
* **Напоминания и таймер**, **погода**, **музыка** (папка `music/`, плюс поиск в Яндекс Музыке, Spotify и SoundCloud в браузере).
* **Смотрит на экран** по горячей клавише `F9` или команде `экран` (нужна модель со зрением).
* **Мини-игры** прямо в чате: угадай число, виселица, камень-ножницы-бумага.
* **Реагирует на систему:** отключил зарядку, сел аккумулятор, пропал интернет, запустил игру или редактор кода.
* **Перетащи файл на неё**, и она прочитает его и скажет, что думает (текст, код, `docx`, картинки, папки; `pdf` при установленном `pypdf`).
* Поглаживание, редкие глитчи, болтовня в тишине, режим *Just Monika*, поздравление с днём рождения.
* Нормальное окно настроек, иконка в трее, автозапуск вместе с Windows.

## Установка

Нужны **Windows 10/11** (программа использует WinAPI) и **Python 3.10+** (проверялось на 3.13).

```bash
git clone <адрес-репозитория>
cd <папка-репозитория>
pip install -r requirements.txt
python monika.py
```

Если ключа нейросети ещё нет, Моника всё равно запустится и сама откроет настройки на вкладке **«Ключи»**.

Структура папки:

```
monika.py
requirements.txt
sprites/        # твои спрайты (в репозитории их нет)
music/          # твои треки, по желанию
monika\\\_files/   # создаётся сама: настройки, память, напоминания
```

## Спрайты

Папки `sprites/`, `music/` и `monika\\\_files/` создаются сами при первом запуске. Положи в `sprites/` картинки **с прозрачным фоном** (`png`, `webp`, `jpg`):

|Файл|Когда показывается|
|-|-|
|`neutral.png`|обычное состояние, запасной вариант|
|`happy.png`, `sad.png`, `smug.png`, `surprised.png`, `worried.png`|соответствующая эмоция|
|`happy\\\_2.png`, `happy\\\_alt.png`…|варианты той же эмоции, выбираются случайно|
|`glitch1.png`, `glitch2.png`…|кадры эффекта глитча (необязательно)|

Если какого-то файла нет, используется `neutral`. Если нет и его, берётся первая картинка из папки. Без спрайтов Моника запустится, но вместо неё будет текстовая подсказка, куда их положить.

**Звук глитча** (необязательно): положи `glitch.mp3` (или `.ogg`, `.wav`) в папку `music/`, он играет во время глитча. Остальные звуки (например, сигнал уведомления) программа создаёт сама.

## Ключ нейросети

Нужен **хотя бы один** вариант. Ключи вводятся в **Настройки → Ключи** либо задаются переменными окружения.

|Вариант|Как подключить|
|-|-|
|**GigaChat** (Сбер)|«Authorization key» из кабинета GigaChat API → поле `GigaChat` или `GIGACHAT\\\_API\\\_KEY`. Область по умолчанию `GIGACHAT\\\_API\\\_PERS` (`GIGACHAT\\\_SCOPE`), модель `GIGACHAT\\\_MODEL`.|
|**OpenRouter**|Ключ с openrouter.ai → поле `OpenRouter` или `OPENROUTER\\\_API\\\_KEY`. Моника сама подбирает бесплатные модели со зрением; зафиксировать модель можно через `MONIKA\\\_MODEL`.|
|**Ollama**|Если Ollama запущена локально, Моника найдёт её сама (`OLLAMA\\\_URL`, `OLLAMA\\\_MODEL`).|
|**Любой OpenAI-совместимый сервис**|`EXTRA\\\_BASE\\\_URL`, `EXTRA\\\_KEY`, `EXTRA\\\_MODEL`; `EXTRA\\\_VISION=0` и `EXTRA\\\_TOOLS=0`, если модель не умеет зрение или вызов инструментов.|
|**Mistral**|`MISTRAL\\\_API\\\_KEY` (модель `MISTRAL\\\_MODEL`).|

Если один вариант не отвечает, Моника пробует следующий. Для скриншотов и картинок нужна модель со зрением; без неё она честно скажет, что не видит.

## Управление

|Действие|Что делает|
|-|-|
|Клик по спрайту|открыть / закрыть поле чата|
|Двойной клик|погладить|
|Провести курсором по голове|погладить|
|Перетаскивание мышью|переместить Монику|
|Клик по пузырю|скрыть реплику|
|`F9`|посмотреть на экран|
|Файл на спрайт|прочитать и прокомментировать|

Команды, которые можно написать в чате:

`настройки` · `экран` · `игра` · `файл <путь>` · `just monika` · `погладить` · `трей` · `выход` · `помощь`

Всё остальное Моника считает обычным разговором. Можно просить её по-человечески: «поставь таймер на 10 минут», «какая погода», «запомни, что я люблю чай».

### Мини-игры

Напиши `игра` и выбери: **угадай число** (7 попыток), **виселица** или **камень-ножницы-бумага**. `стоп` выходит из игры, `сдаюсь` показывает ответ. Результаты сохраняются, и Моника может подколоть тебя по ним.

### Реакции на систему

Можно отключить в **Настройки → Поведение**. Моника замечает: зарядку (отключена, подключена, 20 %, 10 %, 100 %), пропажу и возвращение интернета, запуск игр и редакторов кода.

### Файлы на спрайт

Перетащи файл прямо на Монику. Если перетаскивание не сработало, есть запасной вариант: `файл C:\\\\путь\\\\к\\\\файлу.txt`. В консоли при запуске видно сообщение `\\\[DnD] приём файлов включён`; если там что-то другое, проверь галочку в **Настройки → Поведение** (она применяется после перезапуска).

## Данные, приватность и безопасность

* Всё хранится локально в `monika\\\_files/`: `settings.json` (**ключи лежат открытым текстом**), `memory.json` (история и факты), напоминания, счётчик поглаживаний и `last\\\_screen.jpg` (последний скриншот). **Не публикуй эту папку.**
* **В нейросеть уходит:** текст твоих сообщений, скриншот (только когда ты просишь посмотреть экран) и содержимое файлов, которые ты сам отдал Монике. Выбирай сервис с учётом этого.
* Инструменты Моники ограничены: она читает и пишет файлы **только в своей папке** (запись с твоего подтверждения), открывает музыкальные сайты в браузере, ставит напоминания и управляет своим окном. Запускать произвольные программы и лазить по диску она не умеет.
* Запросы к GigaChat идут с отключённой проверкой SSL-сертификата (`verify=False`). Для GigaChat это распространённый обходной путь из-за российского сертификата, но имей в виду.

## Если что-то не так

* Предупреждение `pkg\\\_resources is deprecated` при запуске от `pygame` безвредно.
* Моника отвечает «Ни один вариант не отвечает» — проверь ключ и интернет, в консоли видно ошибку каждого сервиса.
* Не открывается окно / нет спрайта — проверь, что в `sprites/` лежит хотя бы `neutral.png`.

## English (short)

A Windows desktop companion: Monika from *Doki Doki Literature Club* chats via an LLM (GigaChat, OpenRouter, Ollama or any OpenAI-compatible API), remembers conversations, sets reminders, looks at your screen on `F9`, plays mini-games in chat, reacts to battery/network/games, and reads files you drag onto her. Fan project, not affiliated with Team Salvato; **sprites are not included**, put your own transparent PNGs into `sprites/` (`neutral.png`, `happy.png`, `sad.png`, `smug.png`, `surprised.png`, `worried.png`). Install: `pip install -r requirements.txt`, then `python monika.py` and enter an API key in Settings → Keys. Windows 10/11 only.
